## 框架与资源

- 怪物定义、取帧参数和攻击窗口预编译缓存。公开定义、取帧结果与窗口仍返回副本，调用者不能污染缓存。每种角色共享只读 SpriteFrames，角色播放状态独立。64 个骷髅的图集对象从 3008 个减为 47 个。合成 12000 次取帧基准中位耗时 133594 → 30216 微秒；这是动画逻辑基准，不能解释为整体帧率提高 77%。
- 地牢地板／墙与守城草地／道路／树木保留绘图命令，动态箱子、门、火把、陷阱、角色和塔继续更新。地板使用 480 字节网格缓存，精确网格外保留原矩形判定。
- HUD 按文本变化更新，技能进度持续更新；当前属性与缓存比对防止页面重建或外部修改造成旧值。
- 原始音乐及简中字库保留，使用 433 字形的字体副本与 Vorbis Q5 音乐副本。字体逐字轮廓、宽度和行高一致；音频编码是有损压缩，曲长、声道和循环保持。细节见 `resource-optimization.md`。
- `config/runtime_assets.json` 收录 106 个运行时资源；发布复制另包括全部游戏脚本、场景和资源定义。JSON 拼接路径、宝箱／火把、HUD 图标均明确收录，历史字库及制作记录不会进入成品。

## 专用引擎

匹配 Godot 4.7.2 官方源码：
https://github.com/godotengine/godot/releases/download/4.7.2-stable/godot-4.7.2-stable.tar.xz

官方 SHA-256：`a18ce0ccec3ecc40b0dd6c4f5132ca934e9fb7c2979717940ff32aee1eb35481`。

使用 Visual Studio MSVC 14.51、Windows SDK 10.0.26100.0 与 SCons 4.11.1；源码主／次／补丁版本必须精确为 4.7.2。构建选项见 `config/fortress_2d_template.py`。仅保留 GDScript、Godot 2D 物理、FreeType／高级中文文本、WebP、Ogg／Vorbis、MP3 与兼容渲染；关闭 3D、Vulkan、D3D12 等未使用模块。C++ 运行库静态链接，试玩无需安装编译工具。

开发工程继续保留 MCPRuntimeProbe；发布暂存工程单独移除其 Autoload 和编辑器插件。因此开发工程直接使用标准导出模板，优化发布用下述脚本完成。新玩法若引用本模板没有的引擎类，必须先调整选项并重新编译，不能静默沿用此模板。

## 可重复导出

在项目目录执行：

```powershell
./tools/export_release.ps1
```

可传 `-GodotPath`、`-PythonPath`、`-OutputRoot`。默认在父目录 `builds` 下创建带时间的新目录；同名已有发布目录拒绝覆盖。输出包括独立发布工程、Windows 程序、PCK、必要说明与授权文件、ZIP 和校验 JSON。

模板保存在 `tools/export_templates/fortress_2d_4.7.2.exe`。若需重新编译：下载并校验上述源码，在工具环境安装 SCons 后运行：

```powershell
python tools/build_template.py --engine-source <extracted-source> --jobs 3
```

修改中文或动态素材路径后，先按 `resource-optimization.md` 重新生成字体／音乐／资源清单并验证，再执行 GUT 与发布。生成工具的 Python 依赖不会打入游戏包。
