《堡垒之下》素材来源与鸣谢

游戏使用 Godot Engine 4.7.2 制作。

本版本使用专用 2D 引擎模板；中文字体保留当前游戏所需字形，音乐采用 Ogg Vorbis 压缩副本。原始素材在开发工程中保留。

人物与兽人：Tiny RPG Character Asset Pack 01 v2.0 - Free Soldier & Orc
骷髅、重甲骷髅、吸血鬼：Enemy_Animations_Set
史莱姆：FreeCharactersAnimationsAssetPack
地牢地图、宝箱、陷阱与浮空魔颅：2D Pixel Dungeon Asset Pack v2.0
地表建筑、树木与界面：Tiny Swords (Update 010)
像素特效：Effect and FX Pixel All Free
音乐及部分音效：Minifantasy - Dungeon Audio Pack，Leohpaz
中文字体：Fusion Pixel Font，TakWolf 及原字体贡献者
图标参考资源：IconGodotNode

Godot、字体、音乐及史莱姆的现有许可文件附在本文件夹中。
其余美术来源按项目现有记录列出，尚未补齐作者署名及单独许可文件。
所有第三方素材的版权归各自作者所有。本包为游戏试玩成品，不包含原始素材压缩包。

音乐作者页面：https://leohpaz.itch.io/minifantasy-dungeon-sfx-pack
字体项目：https://github.com/TakWolf/fusion-pixel-font
Godot：https://godotengine.org
