《堡垒之下》中文试玩版

版本：v1.8（优化版）
平台：Windows 64位
引擎：Godot 4.7.2，GL Compatibility

运行方法
将压缩包完整解压，双击“堡垒之下.exe”。无需安装 Godot。
“堡垒之下.exe”和“堡垒之下.pck”需保持同名，并放在同一文件夹。

游玩目标
完成三轮冒险：整备堡垒 → 地牢探索 → 携带目标钥匙从入口墙梯返回 → 建设与升级 → 守城。
已完成轮次的建设成果会保留。失败后可点击“重试”。

操作
W / A / S / D：移动
J / 鼠标左键：剑击
K / 鼠标右键：射箭
E：开门、开箱、拾取、墙梯撤离
鼠标点击塔位：建造或升级箭塔，仅整备及结算时可用
守城时点击敌人：集火
空格 / “加大火力”按钮：暂时提高箭塔射速
Esc：暂停、查看操作或返回主菜单
“声音”按钮：开关音效与音乐

试玩提示
取得目标钥匙后，返回入口墙上的梯子，站在墙前按 E 离开。
普通宝箱提供金币；封印宝箱提供额外金币，但增加本轮守城敌人。
史莱姆会分裂，吸血鬼需要击败两次。
