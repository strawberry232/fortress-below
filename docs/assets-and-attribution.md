# 素材来源与源码发布范围

素材来源依据现有开发工程记录整理。项目使用网络第三方免费资源，代码开发使用了 AI 辅助。

| 用途 | 来源 |
| --- | --- |
| 玩家、弓箭手、兽人 | Tiny RPG Character Asset Pack 01 v2.0 - Free Soldier & Orc |
| 骷髅、重甲骷髅、吸血鬼 | Enemy_Animations_Set |
| 史莱姆 | FreeCharactersAnimationsAssetPack |
| 地牢道具、门、墙梯、火把、陷阱与魔颅 | 2D Pixel Dungeon Asset Pack v2.0 |
| 地表建筑、树木与界面素材 | Tiny Swords (Update 010) |
| 特效 | Effect and FX Pixel All Free |
| 音乐及部分音效 | Minifantasy - Dungeon Audio Pack，Leohpaz |
| 中文字体 | Fusion Pixel Font，TakWolf 及原字体贡献者 |
| 图标参考 | IconGodotNode |

“免费”说明取得资源时的成本，不能视为允许公开再分发原始素材。史莱姆包现有许可明确禁止再分发或转售素材；部分其他美术包尚未补齐作者与单独许可材料。本次源码快照统一排除 `game/assets/`，保留路径清单和已有许可文字，避免将这些原图随源码上传。

此文件不授予任何第三方素材的使用权。需要复现完整游戏时，应从原作者获得资源并遵守对应条款，再按 `docs/asset-files.csv` 的路径在本地配置。路径与哈希用于复现，不是素材下载链接。

GUT 与 Godot MCP Native 为开发依赖，快照保留对应 MIT 许可证。字体等原有许可材料单独保留在 `docs/third-party-licenses/`。项目自身代码尚未选定统一开源许可证。
